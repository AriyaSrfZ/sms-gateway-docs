SOAP — مقدمه

📡 وب‌سرویس SOAP

SOAP مخفف Simple Object Access Protocol است — یک پروتکل مبتنی بر XML برای تبادل اطلاعات بین برنامه‌ها از طریق HTTP. این روش برای سیستم‌هایی مناسب است که از پیش با SOAP یکپارچه شده‌اند.

⚠️
برای پروژه‌های جدید استفاده از وب‌سرویس REST یا پلتفرم ESB v2 توصیه می‌شود. SOAP صرفاً برای سیستم‌های موجود پشتیبانی می‌شود.

آدرس WSDL

http://sms.persiafava.com/webservice/soap/?wsdl

📤 ارسال پیامک (send_sms)

برای ارسال پیامک به یک یا چند گیرنده با امکان زمان‌بندی ارسال در آینده.

SOAP send_sms

پارامترهای ورودی

پارامترنوعاجباریتوضیحات
usernameStringبلهنام کاربری سامانه پیامک
passwordStringبلهرمز عبور سامانه پیامک
sender_numberArrayOfStringبلهشماره فرستنده (آرایه)
receiver_numberArrayOfStringبلهشماره(های) گیرنده (آرایه)
noteArrayOfStringبلهمتن پیامک (آرایه — برای ارسال نظیر به نظیر)
dateArrayOfStringبلهتاریخ ارسال — مقدار 0 یعنی همین لحظه. برای ارسال زمان‌بندی‌شده timestamp Unix وارد کنید.
request_uniqueidArrayOfStringخیرشناسه یکتا برای جلوگیری از ارسال تکراری. مقدار 0 یعنی بررسی نشود. اگر درخواست تکراری باشد، smsidهای قبلی برگردانده می‌شوند.
flashArrayOfStringخیرپیامک فلش: ok یا no
onlysendStringخیرارسال سریع بدون وقفه: ok (تأخیر ۳۰ ثانیه) یا no

پارامترنوعاجباریتوضیحات

ESB v2 — احراز هویت

🔑 احراز هویت ESB v2

تمام متدهای ESB v2 از HTTP Basic Authentication استفاده می‌کنند. رشته احراز هویت را در هر درخواست در هدر Authorization ارسال نمایید.

HTTP Header
Authorization: Basic <رشته-base64-احراز-هویت>
ℹ️
رشته base64 ترکیب username:password به صورت base64-encoded است. در هر درخواست باید ارسال شود.
⚠️
نکته ۱: بیشینه تعداد گیرنده در متد ارسال نظیر به نظیر ۱۰۰ عدد است.
نکته ۲: مقدار status=0 در همه پاسخ‌ها به معنای موفقیت است. هر مقدار دیگر کد خطاست.
ESB v2 — متد اول

📤 ارسال نظیر به نظیر

برای ارسال یک یا چند پیامک به یک یا چند گیرنده (حداکثر ۱۰۰ عدد) با فرستنده‌ها و متن‌های متفاوت. مناسب برای ارسال قبوض خدماتی و پیام‌های شخصی‌سازی‌شده.

⚠️

<?php
/**
 * ارسال پیامک از طریق ESB v2
 *
 * @param string|array $to     شماره گیرنده یا آرایه‌ای از شماره‌ها
 * @param string|array $msg    متن پیام یا آرایه متن‌ها
 * @param string       $from   شماره فرستنده
 * @param string       $type   'p2p' | 'bulk' | 'otp'
 * @return array|WP_Error
 */
function persiafava_send_sms( $to, $msg, $from = '40400000', $type = 'bulk' ) {

    $uid = wp_generate_uuid4(); // شناسه یکتا

    if ( $type === 'otp' ) {
        $endpoint = '3002/Otp';
        $body = [
            'sender'    => $from,
            'recipient' => $to,
            'message'   => $msg,
            'uid'       => $uid,
        ];
    } elseif ( $type === 'p2p' ) {
        $endpoint = '3000/PeerToPeer';
        $body = [
            'senders'    => array_fill( 0, count( (array) $to ), $from ),
            'recipients' => (array) $to,
            'messages'   => (array) $msg,
            'uids'       => array_map( fn() => wp_generate_uuid4(), (array) $to ),
        ];
    } else { // bulk
        $endpoint = '3001/Bulk';
        $body = [
            'sender'     => $from,
            'recipients' => (array) $to,
            'message'    => $msg,
            'uids'       => array_map( fn() => wp_generate_uuid4(), (array) $to ),
        ];
    }

    $response = wp_remote_post(
        SMS_ESB_BASE . ':' . $endpoint,
        [
            'headers' => [
                'Authorization' => 'Basic ' . SMS_ESB_AUTH,
                'Content-Type'  => 'application/json',
            ],
            'body'    => wp_json_encode( $body ),
            'timeout' => 15,
            'sslverify' => false, // در صورت نیاز
        ]
    );

    if ( is_wp_error( $response ) ) {
        return $response; // WP_Error برمی‌گردد
    }

    return json_decode( wp_remote_retrieve_body( $response ), true );
}

پرشیا فاوا می‌تواند وضعیت دلیوری و پیامک‌های دریافتی را به آدرس اختصاصی شما push کند — بدون نیاز به polling.

ارسال وضعیت دلیوری (DLR Push)

زمانی که یک پیامک وضعیت نهایی دریافت کند (یا پس از ۲۴ ساعت)، سیستم یک درخواست POST با Content-Type: application/json به آدرس شما ارسال می‌کند. حداکثر ۱۰۰ وضعیت در هر درخواست ارسال می‌شود.

دریافت پیامک ورودی MO (Push)

پیامک دریافتی بلافاصله پس از وصول به صورت POST (application/x-www-form-urlencoded) به آدرس تنظیم‌شده ارسال می‌شود.
